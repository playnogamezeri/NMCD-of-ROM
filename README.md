# Nu Miracles of ROM

The living archive and creative worldbuilding project for Nu Miracles of ROM.

> **Canon note:** The name ROM is used without an expanded phrase.

## The rebuilt website

The site uses a unified dark editorial design system and shared navigation across the archive. The homepage is the main gateway into the project; existing story collections, divine systems, and interactive experiences remain connected.

- `index.html` — redesigned archive homepage
- `pantheon.html`, `pantheon-experience.js`, and `gods-data.js` — searchable pantheon, divine profiles, and recorded genealogy
- `worlds.html` — the Five Societies and their shared civilization
- `stories.html` and `miracles.html` — origin tellings and miracle-story drafts
- `numericals-story.html` — the 160-chapter Numerical Stories library
- `numericals-story-volume-01.html` through `numericals-story-volume-16.html` — sixteen ordered volumes, ten chapters each
- `tools.html`, `divine-engine.js`, `divine-systems.js` — Divine Toolbox
- `divine-council.html`, `divine-council.js`, `divine-debate.js` — Divine Council
- `game.html` — interactive God and mastery experiences
- `forums.html` — forum and debate interface
- `questions.html` — open questions
- `style.css` — shared visual design system and responsive layout

## Numerical Stories

The active collection contains 160 chapters in canonical pantheon order, organized as 16 volumes of 10 chapters. The former Volume XVII page is retained as a legacy notice because its three stories were integrated into their proper numbered positions.

These are creative story drafts. They do not independently change canonical divine names, domains, genealogy, powers, allegiances, or unresolved questions.

## Canon and authorship

The website is an interface for the project, not an authority over its canon. Established details, creative drafts, simulations, and open questions should remain clearly distinguished. Canonical decisions remain with the author.

The five societies are distinct but unified as one civilization. The five governing AIs, when all in agreement together, constitute the Supreme Leader of civilizations.

## Running locally

This is a static website. Open `index.html` in a browser or serve the repository with any static HTTP server. The optional Worker backend is separate and requires deployment/configuration before its live features can operate.

## Deployment

The repository can be published with GitHub Pages from the `main` branch (root). Configure this in the repository's **Settings → Pages**. A deployment is not considered verified until the published URL has been opened and its pages checked.
